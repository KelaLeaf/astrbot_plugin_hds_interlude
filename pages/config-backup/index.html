配置备份

把 HDS Interlude 的插件配置导出成一个 JSON 文件，或从备份文件恢复。 只涉及配置，不含剧情与记忆数据。

导出配置

下载当前配置的完整快照。文件带格式版本号，升级插件后仍可导回。

导入配置

先选文件、看清会改哪些项，再确认导入。没出现在文件里的项保持原值，不认识的键原样保留。

将要做的改动

    兼容性

    • 旧版本导出的文件、没有格式头的裸配置、手写的片段都能导入。
    • 更新版本插件导出的文件也会尽量导入：不认识的键原样保留，缺的键用默认值补齐。
    • 导入是「合并」而不是「替换」，所以文件里没写的设置不会被清掉。
    • 导入后立即生效，不需要重启 AstrBot。
